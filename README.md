# RecipeShared - Plataforma de Receitas Colaborativas

Uma plataforma para compartilhar e descobrir receitas, desenvolvida com React, TypeScript e TailwindCSS.

## 📋 Sobre o Projeto

Plataforma colaborativa onde usuários poderão criar, compartilhar e descobrir receitas. 
Inclui funcionalidades futuras, como sistema de avaliações, filtros, timer de preparo. 
Conversão de unidades e lista de compras automática.

## 🎯 Objetivos de Aprendizado

Este projeto foi desenvolvido para aprimorar habilidades em:
- React com TypeScript
- Arquitetura de componentes reutilizáveis
- Integração com APIs
- Acessibilidade (a11y)
- SEO
- Design responsivo com TailwindCSS

## 🚀 Tecnologias Utilizadas

- **React 18** - Biblioteca para construção de interfaces
- **TypeScript** - Superset JavaScript com tipagem estática
- **Vite** - Build tool e dev server
- **React Router v6** - Roteamento de páginas
- **TailwindCSS** - Framework CSS utilitário
- **shadcn/ui** - Biblioteca de componentes acessíveis
- **Lucide React** - Biblioteca de ícones
